# FifthRow LCM support

Email [support@fifthrow.com](mailto:support@fifthrow.com) for help with connecting FifthRow LCM, account access, research runs, or data requests. Include the client name, approximate time, operation ID if available, and a description that does not contain confidential data.

Never post passwords, access tokens, OAuth secrets, or private customer documents in a public issue. For setup, background work, complete results, and data boundaries, see the [plugin support guide](plugins/fifthrow-lcm/SUPPORT.md).
